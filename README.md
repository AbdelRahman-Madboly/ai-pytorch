# ai-pytorch

Moving from using PyTorch as a tool to actually understanding it —
autograd, custom modules, training loops, export — from memory.

Following the *PyTorch for Deep Learning* Professional Certificate
(DeepLearning.AI / Laurence Moroney, Coursera, 3 courses). Course labs go in
`_plan/content/`; everything in `src/` I wrote myself.

## When this repo starts
After `ai-math-foundations` hits **v1.0.0**. Gradient descent and the chain rule
need to make sense first.
